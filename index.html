01 How it works

Purpose-locked payments: nobody — not Jàngal, not a middleman, not the school — can redirect the money.

STEP 1
School creates the fee invoice

Or photographs the fee note — AI parses student, class, term, amount (FCFA + sats).

STEP 2
Diaspora parent pays in sats

Funds LOCK in a Lightning hold invoice. Nobody can claim them yet.

STEP 3
School attaches the proof

Enrolment receipt photo → AI vision verifies it against the fee record.

STEP 4
One tap confirms enrolment

The hold invoice settles — school paid in seconds. No confirmation → HTLC times out → automatic refund.

STEP 5
Nostr-signed receipt

Anchors the proof hash + AI verdict, verifiable forever by anyone. Family notified in Wolof.

04 What's real & how to run it

Same code, two modes: the hosted path runs the full hold-invoice state machine in simulation; Docker runs it against real bitcoind + 2 LND regtest nodes.

🐳 Full Lightning stack (real, one command)

bitcoind + lnd-school + lnd-parent + app. First boot mines regtest blocks and opens the channel automatically. Demo codes: 1111 parent · 3333 school · 2222 family.

git clone https://github.com/imspsycho/jangal && cd jangal
docker compose up --build
# → http://localhost:3000

Under the hood

  • Real hold-invoice lifecycle — AddHoldInvoice → payment locked → SettleInvoice / CancelInvoice with automatic refunds
  • AI-verified proof photos — vision verdict (match/mismatch/unclear + named checks), hash + verdict anchored in the Nostr receipt; deterministic mock offline, any OpenAI-compatible vision model via one env var
  • Real Nostr — school keys, signed kind-30078 events, embedded relay (ws://…/nostr), signature verification in the UI
  • Public receipt verifier — /#/verify/<fee_id>, no login, re-verifies every 5 s, WhatsApp-shareable
  • Security by design — server compromise degrades service, cannot redirect money; full threat model in docs/threat-model.md
  • 148 automated checks + 13-step browser journey — RBAC, auth bypass, confirm/reject races, evidence-swap detection, XSS, security headers, rate limits, load
  • Trilingual AI assistant — Wolof / Français / English, fee-note parsing, live FX (mempool.space × XOF peg) with offline fallback
  • School KPIs + CSV — median lock→settle, refund rate, AI coverage, per-term totals, one-click ledger export
